# Linking LLVM Bitcode

In this tutorial, we'll learn how to link multiple `.bc` (bitcode) files together using LLVM tools.

**Prerequisite:** Install the `llvm-link` tool (included with LLVM).

---

## Hands-On Example: Linking Two Modules

### Step 1: Create Source Files with Cross-References

To demonstrate linking, we'll create two C files where one references a function defined in the other.

Create `test1.c`:

```c
int func(int a) {
    a = a * 2;
    return a;
}
```

Create `test2.c`:

```c
#include <stdio.h>

extern int func(int a);

int main() {
    int num = 5;
    num = func(num);
    printf("number is %d\n", num);
    return num;
}
```

### Step 2: Convert C Code to Bitcode

First, generate LLVM IR from the C files, then convert to bitcode:

```bash
# Generate LLVM IR
clang -emit-llvm -S test1.c -o test1.ll
clang -emit-llvm -S test2.c -o test2.ll

# Convert IR to bitcode
llvm-as test1.ll -o test1.bc
llvm-as test2.ll -o test2.bc
```

### Step 3: Link the Bitcode Files

Use `llvm-link` to combine the two bitcode files:

```bash
llvm-link test1.bc test2.bc -o output.bc
```

This produces a single linked bitcode file containing both modules.

> **Tip:** Add the `-S` flag to output human-readable IR instead:
> ```bash
> llvm-link test1.bc test2.bc -S -o output.ll
> ```

### How It Works

`llvm-link` performs the fundamental function of a linker at the LLVM IR level:

- Resolves external references between modules
- Merges function and variable definitions
- Produces a single unified bitcode module

| Input | Output | Description |
|-------|--------|-------------|
| `test1.bc` | - | Contains `func()` definition |
| `test2.bc` | - | Contains `main()` with external reference to `func()` |
| - | `output.bc` | Linked module with both functions |

> **Note:** `llvm-link` only works with bitcode files, not object files or executables.

# Executing LLVM Bitcode

## Prerequisites

To execute LLVM bitcode directly, you need the `lli` tool (LLVM Interpreter/JIT).

---

## Hands-On Example: Running Bitcode

### Step 1: Execute the Linked Bitcode

Using the `output.bc` from the previous example:

```bash
lli output.bc
```

### Step 2: Verify the Output

```
number is 10
```

This confirms that the linking was successful:

```
┌─────────────────────────────────────────────────────────────────────┐
│                        Execution Flow                               │
├─────────────────────────────────────────────────────────────────────┤

│   │      │      │             │             │                       │
```

### How It Works

The `lli` command executes LLVM bitcode using a **JIT (Just-In-Time) compiler**:

| Feature | Description |
|---------|-------------|
| **JIT Compilation** | Compiles bitcode to native machine code at runtime |
| **Immediate Execution** | No need to create an executable file first |
| **Platform Independent** | Same bitcode runs on any supported architecture |
