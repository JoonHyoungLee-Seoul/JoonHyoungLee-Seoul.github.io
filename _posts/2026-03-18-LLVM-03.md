# Transforming LLVM IR with the opt Tool

In this tutorial, we'll use the `opt` tool to transform IR into different forms and apply various optimizations to IR code.

**Prerequisite:** Install the `opt` tool (included with LLVM).

---

## Hands-On Example: Memory to Register Promotion

### Step 1: Create the C Source File

Create `multiply.c`:

```c
int mult() {
    int a = 5;
    int b = 3;
    int c = a * b;
    return c;
}
```

### Step 2: Generate LLVM IR

```bash
clang -emit-llvm -S multiply.c -o multiply.ll
```

The generated `multiply.ll`:

```llvm
; ModuleID = 'multiply.c'
source_filename = "multiply.c"
target datalayout = "e-m:e-i8:8:32-i16:16:32-i64:64-i128:128-n32:64-S128"
target triple = "aarch64-unknown-linux-gnu"

; Function Attrs: noinline nounwind uwtable
define dso_local i32 @mult() #0 {
  %1 = alloca i32, align 4
  %2 = alloca i32, align 4
  %3 = alloca i32, align 4
  store i32 5, i32* %1, align 4
  store i32 3, i32* %2, align 4
  %4 = load i32, i32* %1, align 4
  %5 = load i32, i32* %2, align 4
  %6 = mul nsw i32 %4, %5
  store i32 %6, i32* %3, align 4
  %7 = load i32, i32* %3, align 4
  ret i32 %7
}

attributes #0 = { noinline nounwind uwtable ... }
```

Notice that this unoptimized IR uses **stack memory** (`alloca`, `store`, `load`) for local variables.

### Step 3: Apply the mem2reg Pass

The `mem2reg` pass promotes memory references to register references, enabling SSA form:

```bash
opt -passes=mem2reg -S multiply.ll -o multiply1.ll
```

### Step 4: Examine the Optimized IR

The optimized `multiply1.ll`:

```llvm
; ModuleID = 'multiply.ll'
source_filename = "multiply.c"
target datalayout = "e-m:e-i8:8:32-i16:16:32-i64:64-i128:128-n32:64-S128"
target triple = "aarch64-unknown-linux-gnu"

; Function Attrs: noinline nounwind uwtable
define dso_local i32 @mult() #0 {
  %1 = mul nsw i32 5, 3
  ret i32 %1
}

attributes #0 = { noinline nounwind uwtable ... }
```

### What Changed?

```
┌─────────────────────────────────────────────────────────────────────┐
│                         Before (mem2reg)                            │
├─────────────────────────────────────────────────────────────────────┤
│  %1 = alloca i32, align 4           ; allocate stack for 'a'        │
│  %2 = alloca i32, align 4           ; allocate stack for 'b'        │
│  %3 = alloca i32, align 4           ; allocate stack for 'c'        │
│  store i32 5, i32* %1, align 4      ; store 5 to memory             │
│  store i32 3, i32* %2, align 4      ; store 3 to memory             │
│  %4 = load i32, i32* %1, align 4    ; load 'a' from memory          │
│  %5 = load i32, i32* %2, align 4    ; load 'b' from memory          │
│  %6 = mul nsw i32 %4, %5            ; multiply                      │
│  store i32 %6, i32* %3, align 4     ; store result to memory        │
│  %7 = load i32, i32* %3, align 4    ; load result from memory       │
│  ret i32 %7                                                         │
└─────────────────────────────────────────────────────────────────────┘
                                 ▼
                             mem2reg
                                 ▼
┌─────────────────────────────────────────────────────────────────────┐
│                         After (mem2reg)                             │
├─────────────────────────────────────────────────────────────────────┤
│  %1 = mul nsw i32 5, 3              ; direct computation            │
│  ret i32 %1                         ; return result                 │
└─────────────────────────────────────────────────────────────────────┘
```

The `mem2reg` pass eliminated all stack allocations and memory operations, replacing them with direct register operations.

## Available Optimization Passes

The `opt` tool supports many optimization passes. Here are some commonly used ones:

| Pass | Description |
|------|-------------|
| `mem2reg` | Promote memory to registers (enables SSA) |
| `instcombine` | Combine redundant instructions |
| `dce` | Dead code elimination |
| `adce` | Aggressive dead code elimination |
| `constprop` | Constant propagation |
| `deadargelim` | Dead argument elimination |
| `globaldce` | Dead global elimination |
| `globalopt` | Global variable optimization |
| `gvn` | Global value numbering |
| `inline` | Function inlining |
| `licm` | Loop invariant code motion |
| `loop-unswitch` | Loop unswitching |
| `simplifycfg` | Simplify control flow graph |
| `tailcallelim` | Tail call elimination |
| `sink` | Code sinking |
| `memcpyopt` | Optimize memory copy operations |

### Running Multiple Passes

You can chain multiple passes together:

```bash
opt -passes="mem2reg,instcombine,dce" -S input.ll -o output.ll
```
