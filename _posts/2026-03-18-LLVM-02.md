# Cross-Compiling with Clang/LLVM

## What is Cross-Compilation?

**Cross-compilation** is the process of building binaries on one platform (e.g., x86) that will run on a different platform (e.g., ARM).

| Term | Definition |
|------|------------|
| **Host Machine** | The machine where the binary is built |
| **Target Machine** | The machine where the binary will run |
| **Native Compiler** | Compiles code for the same platform it runs on |
| **Cross-Compiler** | Compiles code for a different platform |

In this tutorial, we'll cross-compile on an x86_64 host platform to produce binaries for an ARM target platform.

---

## Prerequisites

Before starting, ensure you have the required packages installed on your host platform:
- `cmake`
- `ninja-build`
- `llvm`
- `clang`

> **Note:** The setup process varies significantly depending on your OS and version. The examples in this tutorial were tested on Mac with LLVM 14+.

## Converting C Source Code to LLVM Assembly

### Step 1: Create the C Source File

Create a file named `multiply.c`:

```c
int mult() {
    int a = 5;
    int b = 3;
    int c = a * b;
    return c;
}
```

### Step 2: Generate LLVM IR from C Code

```bash
clang -emit-llvm -S multiply.c -o multiply.ll
```

### Step 3: Examine the Generated IR

The generated `multiply.ll` will look like this:

```llvm
; ModuleID = 'multiply.c'
source_filename = "multiply.c"
target datalayout = "e-m:e-i8:8:32-i16:16:32-i64:64-i128:128-n32:64-S128"
target triple = "aarch64-unknown-linux-gnu"

; Function Attrs: noinline nounwind uwtable
define dso_local i32 @mult() #0 {
  %1 = alloca i32, align 4
  %2 = alloca i32, align 4
  %3 = alloca i32, align 4
  store i32 5, i32* %1, align 4
  store i32 3, i32* %2, align 4
  %4 = load i32, i32* %1, align 4
  %5 = load i32, i32* %2, align 4
  %6 = mul nsw i32 %4, %5
  store i32 %6, i32* %3, align 4
  %7 = load i32, i32* %3, align 4
  ret i32 %7
}

attributes #0 = { noinline nounwind uwtable ... }
```

> **Alternative:** You can also use `cc1` to generate the same IR:
> ```bash
> clang -cc1 -emit-llvm multiply.c -o multiply.ll
> ```

### How It Works

The process of converting C code to IR involves several stages:

1. **Lexing** - Breaks C code into tokens (identifiers, literals, operators, etc.)
2. **Parsing** - Constructs an Abstract Syntax Tree (AST) using context-free grammar
3. **Semantic Analysis** - Validates the code for semantic correctness
4. **IR Generation** - Produces LLVM IR from the analyzed code

## Converting IR to LLVM Bitcode

**Prerequisite:** Install the `llvm-as` tool.

### Step 1: Create an IR File

Create `test.ll`:

```llvm
define i32 @mult(i32 %a, i32 %b) {
  %1 = mul nsw i32 %a, %b
  ret i32 %1
}
```

### Step 2: Convert to Bitcode

```bash
llvm-as test.ll -o test.bc
```

> **Tip:** You can inspect the bitcode file contents using `hexdump`.

### How It Works

`llvm-as` is the LLVM assembler that converts human-readable LLVM IR (.ll) into LLVM bitcode (.bc).

---

## Converting LLVM Bitcode to Target Machine Assembly

**Prerequisite:** Install the `llc` (LLVM static compiler) tool.

### Step 1: Generate Assembly from Bitcode

```bash
llc test.bc -o test.s
```

### Step 2: Examine the Generated Assembly

The generated `test.s` will contain target-specific assembly:

```asm
	.text
	.file	"test.ll"
	.globl	mult                            // -- Begin function mult
	.p2align	2
	.type	mult,@function
mult:                                   // @mult
	.cfi_startproc
// %bb.0:
	mul	w0, w0, w1
	ret
.Lfunc_end0:
	.size	mult, .Lfunc_end0-mult
	.cfi_endproc
                                        // -- End function
	.section	".note.GNU-stack","",@progbits
```

> **Alternative:** You can also use Clang directly:
> ```bash
> clang -S test.bc -o test.s -fomit-frame-pointer
> ```

### How It Works

The `llc` command compiles LLVM bitcode to assembly for a specific architecture. If no target architecture is specified, it defaults to the host machine's architecture.

---

## Converting LLVM Bitcode Back to IR (Disassembly)

**Prerequisite:** Install the `llvm-dis` tool.

### Step 1: Disassemble Bitcode to IR

```bash
llvm-dis test.bc -o test.ll
```

### Step 2: Verify the Output

The generated IR should match the original:

```llvm
; ModuleID = 'test.bc'
define i32 @mult(i32 %a, i32 %b) {
  %1 = mul nsw i32 %a, %b
  ret i32 %1
}
```

This confirms that the conversion between IR and bitcode is lossless.

### How It Works

`llvm-dis` is the LLVM disassembler that converts LLVM bitcode (.bc) back into human-readable LLVM IR (.ll).

## Summary: LLVM Toolchain Overview

```
                        LLVM Compilation Pipeline
═══════════════════════════════════════════════════════════════════════

  ┌───────────────┐
  │   C/C++ Code  │
  │  (.c / .cpp)  │
  └───────┬───────┘
          │
          │  clang -emit-llvm -S
          ▼
  ┌───────────────┐         llvm-as         ┌───────────────┐
  │   LLVM IR     │ ──────────────────────▶ │   Bitcode     │
  │    (.ll)      │                         │    (.bc)      │
  │               │ ◀────────────────────── │               │
  │  Human-       │        llvm-dis         │  Binary       │
  │  Readable     │                         │  Format       │
  └───────┬───────┘                         └───────┬───────┘
          │                                         │
          │  opt -passes=...                        │
          │  (Optimization)                         │
          ▼                                         │
  ┌───────────────┐                                 │
  │ Optimized IR  │                                 │
  │    (.ll)      │                                 │
  └───────┬───────┘                                 │
          │                                         │
          └─────────────────┬───────────────────────┘
                            │
                            │  llc (or clang -S)
                            ▼
                    ┌───────────────┐
                    │   Assembly    │
                    │     (.s)      │
                    │               │
                    │  Target-      │
                    │  Specific     │
                    └───────┬───────┘
                            │
                            │  as (assembler)
                            ▼
                    ┌───────────────┐
                    │ Object File   │
                    │    (.o)       │
                    └───────┬───────┘
                            │
                            │  ld (linker)
                            ▼
                    ┌───────────────┐
                    │  Executable   │
                    │   Binary      │
                    └───────────────┘

═══════════════════════════════════════════════════════════════════════
```

### Tool Reference

| Tool | Function | Input | Output |
|------|----------|-------|--------|
| `clang -emit-llvm -S` | Frontend compilation | `.c` / `.cpp` | `.ll` |
| `llvm-as` | Assembler | `.ll` | `.bc` |
| `llvm-dis` | Disassembler | `.bc` | `.ll` |
| `opt` | Optimizer | `.ll` / `.bc` | `.ll` / `.bc` |
| `llc` | Static compiler | `.ll` / `.bc` | `.s` |
