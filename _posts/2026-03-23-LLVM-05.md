# Using the Clang C Frontend

In this tutorial, we'll explore different ways to use the Clang frontend beyond simple compilation.

**Prerequisite:** Install the `clang` tool (included with LLVM).

---

## Clang as a High-Level Compiler

### Step 1: Create a Simple C Program

Create `test.c`:

```c
#include <stdio.h>

int main() {
    printf("hello world\n");
    return 0;
}
```

### Step 2: Compile and Run

```bash
clang test.c
./a.out
```

Output:

```
hello world
```

Clang compiles the C source file into an executable binary (`a.out`).

---

## Clang as a Preprocessor

### Step 1: Create a File with Macros

Create `test.c`:

```c
#define MAX 100
void func() {
    int a[MAX];
}
```

### Step 2: Run the Preprocessor

Use the `-E` flag to run only the preprocessor stage:

```bash
clang test.c -E
```

Output:

```c
# 1 "test.c"
# 1 "<built-in>" 1
# 1 "<built-in>" 3
# 381 "<built-in>" 3
# 1 "<command line>" 1
# 1 "<built-in>" 2
# 1 "test.c" 2

void func() {
    int a[100];
}
```

Notice that `MAX` has been replaced with `100` - the macro has been expanded.

## Viewing the Abstract Syntax Tree (AST)

Use the `-ast-dump` flag to see the AST representation:

```bash
clang -cc1 test.c -ast-dump
```

Output (truncated):

```
TranslationUnitDecl 0x34c5eb78 <<invalid sloc>> <invalid sloc>
|-TypedefDecl 0x34c5f9c0 <<invalid sloc>> implicit __int128_t '__int128'
| `-BuiltinType 0x34c5f140 '__int128'
|-TypedefDecl 0x34c5fa30 <<invalid sloc>> implicit __uint128_t 'unsigned __int128'
| `-BuiltinType 0x34c5f160 'unsigned __int128'
...
```

> **Note:** The `-cc1` option ensures that the compiler frontend is Clang (bypassing the driver).

## Generating LLVM IR

Use `-S -emit-llvm` to generate LLVM assembly:

```bash
clang test.c -S -emit-llvm -o -
```

Output:

```llvm
; ModuleID = 'test.c'
source_filename = "test.c"
target datalayout = "e-m:e-i8:8:32-i16:16:32-i64:64-i128:128-n32:64-S128"
target triple = "aarch64-unknown-linux-gnu"

; Function Attrs: noinline nounwind optnone uwtable
define dso_local void @func() #0 {
  %1 = alloca [100 x i32], align 4
  ret void
}

attributes #0 = { noinline nounwind optnone uwtable ... }
```

The `-S` flag generates assembly (instead of object code), and `-emit-llvm` outputs LLVM IR instead of target assembly.

---

## Generating Target Machine Assembly

Use only the `-S` flag to generate target-specific assembly:

```bash
clang -S test.c -o -
```

Output (ARM64 assembly):

```asm
        .text
        .file   "test.c"
        .globl  func                            // -- Begin function func
        .p2align        2
        .type   func,@function
func:                                           // @func
        .cfi_startproc
// %bb.0:
        sub     sp, sp, #416
        str     x29, [sp, #400]                 // 8-byte Folded Spill
        .cfi_def_cfa_offset 416
        .cfi_offset w29, -16
        ldr     x29, [sp, #400]                 // 8-byte Folded Reload
        add     sp, sp, #416
        ret
.Lfunc_end0:
        .size   func, .Lfunc_end0-func
        .cfi_endproc
                                                // -- End function
        .ident  "Ubuntu clang version 14.0.0-1ubuntu1.1"
        .section        ".note.GNU-stack","",@progbits
```

## Summary: Clang Compilation Stages

Clang can act as different tools depending on the flags provided:

```
┌─────────────────────────────────────────────────────────────────────┐
│                     Clang Compilation Pipeline                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   Source Code (.c)                                                  │
│        │                                                            │
│        │  clang -E                                                  │
│        ▼                                                            │
│   ┌─────────────┐                                                   │
│   │ Preprocessor │ → Macro expansion, include processing            │
│   └──────┬──────┘                                                   │
│          │                                                          │
│          │  clang -cc1 -ast-dump                                    │
│          ▼                                                          │
│   ┌─────────────┐                                                   │
│   │   Parser    │ → Abstract Syntax Tree (AST)                      │
│   └──────┬──────┘                                                   │
│          │                                                          │
│          │  clang -S -emit-llvm                                     │
│          ▼                                                          │
│   ┌─────────────┐                                                   │
│   │  IR CodeGen │ → LLVM IR (.ll)                                   │
│   └──────┬──────┘                                                   │
│          │                                                          │
│          │  clang -S                                                │
│          ▼                                                          │
│   ┌─────────────┐                                                   │
│   │  Backend    │ → Target Assembly (.s)                            │
│   └──────┬──────┘                                                   │
│          │                                                          │
│          │  clang (default)                                         │
│          ▼                                                          │
│   ┌─────────────┐                                                   │
│   │  Executable │ → Binary (a.out)                                  │
│   └─────────────┘                                                   │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### Clang Flag Reference

| Flag | Stage | Output |
|------|-------|--------|
| `-E` | Preprocessor only | Expanded source code |
| `-cc1 -ast-dump` | Parse and dump AST | AST tree structure |
| `-S -emit-llvm` | Generate LLVM IR | `.ll` file |
| `-S` | Generate assembly | `.s` file |
| (none) | Full compilation | Executable binary |

> **Tip:** Run `clang --help` to see the complete list of available options.
